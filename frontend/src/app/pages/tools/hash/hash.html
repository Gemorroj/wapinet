Хэш — результат односторонней функции: из данных получается строка фиксированной длины. Одинаковые данные дают одинаковый хэш, а изменение хотя бы одного байта меняет его целиком. Восстановить данные из хэша нельзя.

Чтобы проверить скачанный файл, посчитайте его хэш и сравните с тем, который опубликовал автор. Сравнивать нужно всю строку целиком, без учёта регистра и пробелов.

SHA-256, SHA-512
Универсальный выбор: целостность файлов, подписи, TLS, контейнеры.
SHA-224, SHA-384, SHA-512/224, SHA-512/256
Когда протокол или политика требует конкретную длину.
SHA3-224…SHA3-512
Если нужен SHA-3 по требованию или независимость от SHA-2.
RIPEMD-160
Bitcoin и старые системы.
CRC32, CRC32C
Быстрая проверка целостности: zip, gzip, PNG, диски. От подмены не защищает.
MD5, SHA-1
Только сверить со старой контрольной суммой. Для защиты не годятся.
  • Необратим: из хэша нельзя получить исходные данные.
  • Не подтверждает автора: для этого нужна цифровая подпись или HMAC с ключом.
  • Не заменяет шифрование: хэш ничего не скрывает.
