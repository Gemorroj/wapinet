Unicode — стандарт кодирования символов. Каждому символу назначается code point вида U+1F600. Диапазон code points — от U+0000 до U+10FFFF.

Code point
Число, которое идентифицирует символ в стандарте Unicode.
UTF-8
Кодировка переменной длины: 1–4 байта на code point.
UTF-16
Кодировка из 16-битных code units; символы выше U+FFFF занимают суррогатную пару.
Графема
То, что человек воспринимает как один символ. Может состоять из нескольких code points.
Нормализация
Приведение текста к NFC/NFD, чтобы одинаковые по смыслу символы сравнивались корректно.

Эмодзи, флаги, диакритические знаки и ZWJ-последовательности состоят из нескольких code points. Поэтому «длина строки» в байтах, UTF-16 и графемах может отличаться. Для HTML используйте numeric/named entities, для JS — \u{...} или суррогатную пару, для CSS — escape вида \1F600.

Не переводит текст, не проверяет орфографию и не заменяет текстовый редактор.

Отображение зависит от шрифта и браузера: некоторые символы и эмодзи могут выглядеть по-разному или отсутствовать в системе.

Первоисточник — unicode.org; таблица символов — unicode.org/charts; эмодзи — полный список эмодзи.

Спецификации: UAX #44 (UCD), UAX #29 (сегментация), UAX #15 (нормализация), UTS #51 (эмодзи), RFC 3629 (UTF-8).
